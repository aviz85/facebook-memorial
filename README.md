# Facebook Memorial Feed - יום הזיכרון

תוסף דפדפן המחליף את הפיד בפייסבוק בתמונות זיכרון של הנופלים ביום הזיכרון לחללי מערכות ישראל ונפגעי פעולות האיבה.

## מבנה הפרויקט

הפרויקט מורכב משלושה חלקים עיקריים:

1. **תוסף לדפדפן כרום** - מחליף את הפיד בפייסבוק בתמונות זיכרון
2. **אתר Next.js** - מאפשר העלאת תמונות חדשות ודף ניהול למנהלים
3. **Supabase Backend** - מאחסן את הנתונים והתמונות

## דרישות המערכת

- Node.js 18.0.0 ומעלה
- חשבון Supabase (ניתן ליצור חינם)
- חשבון Vercel (לאירוח אתר Next.js)
- דפדפן כרום או אדג' (לתוסף)

## הוראות התקנה

### Supabase Setup

1. צור פרויקט חדש ב-Supabase
2. הפעל את ה-SQL הנמצא בקובץ `supabase-setup.sql` בעורך ה-SQL של Supabase
3. העתק את ה-URL של הפרויקט ואת מפתח ה-Anon Key מהגדרות API של Supabase

### הגדרת אתר Next.js

1. התקן את התלויות:
```bash
npm install
```

2. צור קובץ `.env.local` והכנס את פרטי הגישה של Supabase:
```
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

3. הפעל את הפרויקט לפיתוח מקומי:
```bash
npm run dev
```

4. לפרסום לסביבת הייצור, העלה את הפרויקט ל-Vercel:
```bash
npx vercel
```

### הגדרת תוסף כרום

1. פתח את הקובץ `chrome-extension/config.js` והכנס את פרטי ה-Supabase שלך:
```javascript
SUPABASE_URL: 'your-supabase-url',
SUPABASE_ANON_KEY: 'your-supabase-anon-key',
```

2. פתח את הדפדפן בכתובת `chrome://extensions/`
3. הפעל את "מצב מפתח" (Developer Mode)
4. לחץ על "טען תוסף לא ארוז" (Load unpacked)
5. בחר את תיקיית `chrome-extension`

## שימוש באתר

### דף ההעלאה הציבורי

דף ההעלאה הציבורי נמצא בכתובת `/submit` ומאפשר לכל משתמש להעלות תמונה ושם של נופל. התמונות עוברות לאישור מנהל לפני הצגתן בתוסף.

### דף הניהול

דף הניהול נמצא בכתובת `/dashboard` ומאפשר למשתמשים עם הרשאות מנהל לאשר תמונות חדשות. כדי להפוך משתמש למנהל, יש להפעיל את הפונקציה הבאה ב-SQL עורך של Supabase:

```sql
SELECT make_user_admin('admin@example.com');
```

## שימוש בתוסף

התוסף פועל אוטומטית ביום הזיכרון. ניתן להפעיל אותו גם בימים אחרים באמצעות הגדרות התוסף (לחיצה ימנית על אייקון התוסף > הגדרות).
